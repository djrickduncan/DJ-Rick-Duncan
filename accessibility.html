Accessibility

Accessibility

This site is built with the intent to meet WCAG 2.2 Level AA wherever practical. That includes semantic HTML5, a logical heading structure, a skip-to-content link, visible keyboard focus states, sufficient colour contrast, descriptive alt text, an accessible no-JavaScript navigation menu, and support for reduced-motion preferences.

Ongoing commitment

Accessibility is an ongoing effort rather than a one-time checklist. As content and pages are added, they are built to the same standard as the rest of the site.

Known limitations

Some imagery on this site is currently placeholder artwork rather than final photography; alt text describes the intended final image. This will be reviewed again once real assets are added.

Reporting an issue

If you encounter an accessibility barrier anywhere on this site, please get in touch at bookings@[DOMAIN].com describing the page and the issue, so it can be fixed.
